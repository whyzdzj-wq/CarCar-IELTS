# CarCarIELTS

把每个答案，放回原文。

**65套原创雅思阅读练习（试用版）｜195篇文章｜2600个计分点**

[下载离线版 ZIP](https://github.com/whyzdzj-wq/CarCarIELTS/raw/refs/heads/main/CarCarIELTS-Offline.zip) · [查看更新与测试报告](./TEST-REPORT.md) · [反馈问题](https://github.com/whyzdzj-wq/CarCarIELTS/issues)

## 怎么使用

1. 下载上方离线ZIP，并完整解压。
2. 使用Chrome或Edge打开解压目录里的 **index.html**，无需安装、无需联网。
3. 选择试卷；练习模式点击Passage 1、2、3分别进行，考试模式完成整套40个计分点。

请先解压，不要在压缩包预览窗口内直接运行。当前提供离线使用版，GitHub Pages在线入口尚未启用。

## 主要功能

|功能|说明|
|---|---|
|单篇练习|答案＋原文依据；依据选填，单题核对直接显示结果，交卷才确认|
|整套考试|3篇文章、40个计分点、60分钟；顶部切换Passage 1、2、3|
|阅读布局|文章与题目分列、独立调整字号，中间分隔线可拖动；右侧连续展示题目，摘要填空嵌入段落|
|阅读辅助|字号调节、原文搜索、文章及题目黄色高亮、收藏|
|成绩与复盘|正确率、9分制参考分、原文证据定位反馈与紧凑解析、错题及历史记录|
|首页参考分|按已核对或已交卷的练习结果折算，同题取最近一轮已核对练习结果|
|离线保存|当前设备浏览器内保存记录，可导出/导入JSON备份和导出CSV成绩|

手机可切换文章与题目。空卷或部分作答也能交卷，未答按错误计分；核对后在原答题位置显示正确答案，并标记错误。

## 题库与评分说明

- 当前可用65套，每套3篇、40个计分点；未把隔离候选稿计入正式题库。
- 全部材料为原创模拟练习，**不是官方IELTS真题**，与雅思考试主办机构无官方关联。
- 每题保留标准答案、原文定位和解析。程序校验通过不代表已经独立教研逐题审定，仍可能有语言或歧义问题。
- 阅读参考分按正确率折算，不能代替正式考试成绩或真实水平预测。练习题量较少、重复作答和看过解析都会影响代表性。
- 星级难度为内容指标估计，支持半星；尚未覆盖流程图、图示标注、句尾匹配等全部官方题型。

## 数据与备份

作答、笔记、收藏和高亮保存在当前设备浏览器。换浏览器、移动离线文件或更新版本前，请从 **更多 → 导入 / 备份 → 导出 JSON 备份** 保存记录；记录不会自动跨设备同步。仓库发布文件不包含个人学习记录。
