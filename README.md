# 卡卡IELTS · CarCar IELTS

65套原创雅思阅读练习（试用版），非官方IELTS真题。

[下载离线版ZIP](./CarCar-IELTS-Offline.zip) · [本次更新与测试](./TEST-REPORT.md)


解压后双击 index.html，无需安装或联网。建议Chrome/Edge。不要在ZIP预览窗口里直接运行，请先完整解压。

当前题库65套、195篇、2600个计分点，本次定版为65套；题目尚未独立教研审校，非官方IELTS真题。

先选择试卷。练习点击Passage 1、2或3分别进行，已有作答的篇目标蓝；依据选填，单题核对不弹确认。考试完成整套，交卷时确认。允许空卷或部分交卷，未答按错计分，给出正确率和非官方9分制参考分。

文章、题干和选项选中文字可黄色高亮；桌面拖动中间分隔线调整比例，手机切换文章/题目。计时精确到秒。

记录保存在当前浏览器。更新或移动文件、切换浏览器前，请在“更多→导入/备份”导出JSON备份。若浏览器禁止本地存储，会显示警告；不要关闭未备份的会话。
